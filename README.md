# 🎓 Student Enrollment & Performance Dashboard

An interactive Power BI data visualization project designed to track student demographics, course enrollments, and academic performance metrics.

## 📊 Project Overview
This dashboard provides institutional stakeholders and educators with clear, actionable insights into student distribution across programs and academic performance across various courses. 

### Key Performance Indicators (KPIs)
- **Total Enrollments:** 39
- **Total Students:** 22
- **Average Score:** 79.08

## 🔍 Key Features & Visualizations
- **Program Breakdown:** Visualizes student distribution across Computer Science, Information Technology, and Business Administration using a clear pie chart and categorical breakdown.
- **Enrollment Analysis:** Bar chart tracking total enrollments grouped by specific course names.
- **Performance Tracking:** Comparative bar chart displaying average scores per course name.
- **Interactive Filtering:** Slicers allowing dynamic filtering by academic program.

## 🛠️ Tools & Technologies Used
- **Power BI:** Data modeling, DAX measures, and interactive dashboard design.
- **Data Source:** Cleaned and transformed relational student datasets.
- **Git & GitHub:** Version control and portfolio documentation.
